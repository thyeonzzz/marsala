# Marsala

一套应用于品牌咨询和营销策划领域的可执行知识（Executable Knowledge）——以 Markdown 文件承载判断逻辑、工作流程与质量标准的策略系统，与 Agent Runtime 解耦，可在不同平台加载运行。

Marsala 不做执行，只做判断：面对一个商业问题，给出明确的方向、讲清背后的理由，并说明如何验证这个方向对不对。

**Beta 3.5.0 · 本仓库为唯一权威版本（`main` 分支）**

---

## 理论结构：双通道各有一套三问三层

Marsala 的研究对象分两条支线，各自有顶层理论：

| 支线 | 理论文件 | 回答的问题 | 三层结构 |
|------|---------|-----------|---------|
| 品牌咨询 | `skills/brand-theory.md` | 品牌如何建立？如何讲述自己？如何长期经营？ | 立身 / 表达 / 存续 |
| 营销策划 | `skills/campaign-theory.md` | 这一波为什么现在打？打给谁、抢哪个时刻？怎么算赢？ | 时机 / 触达 / 沉淀 |

**campaign 是品牌表达的时间切片。** 品牌理论回答品牌应该是什么，战役理论回答这一波怎么把品牌表达出去并算清账。全管线先读品牌理论，再承接战役理论。

## 架构：一中枢六模块

- 🧠 **中枢（客户总监）**：拆解 Brief、调度协作、整合交付、管线熔断
- 🧩 **六个模块**：商业战略 / 市场研究 / 消费者洞察 / 品牌定位 / 创意方向 / 媒介策划
- **双模式**：品牌咨询（模块一~四）与营销策划（模块五~六）——一个入口，按问题信号分流
- **四层审查**：证据治理 / P&L 经营 / 组织政治 / 危机应对

## 判断体系：真实 → 正确 → 优秀

Marsala 的判断质量由三级递进保证：

| 层级 | 做法 |
|------|------|
| **真实** | 证据按来源与时效双重定权，弱的降级、不硬撑；输出附证据等级与数据时点 |
| **正确** | 候选方向用数据逐组淘汰，留下的必须能回答为什么不是它、什么能证明它错 |
| **优秀** | 创意从被验证的机制里长出来，过品牌识别 / 竞争隔离 / 归因三关，靠品味档案沉淀风格 |

## 关键机制

- **证据治理**（`skills/evidence-governance.md`）：来源等级（E1-E6）× 时效档位（T1-T3），弱证据降级；仅当全部依赖弱证据且无反证路径时熔断
- **可证伪定位**（`skills/hand-4-brand-strategy.md`）：九道闸门，每层输出可验证、可推翻、可回溯
- **创意层**（`skills/creative-layer.md`）：上半场生成纪律（骨架扫描 → 品类适配 → 品牌事实注入），下半场品味选择（五测 + 拥有 + 反例）
- **品牌叙事**（`skills/hand-4-brand-strategy.md`）：叙事四性检验（一致 / 语境 / 真实 / 公共）、用户关系四阶段（告知 / 说服 / 陪伴 / 共创）、文化叙事三根基（产业 / 当代性 / 在地化）
- **小内容策略**（`skills/hand-5-creative-direction.md`）：从风格竞争转向表达方式竞争，品牌人格从被设计到被感知
- **自设 Brief**（`skills/self-brief.md`）：提前 6-8 周预测品牌部的 brief，练向前看的判断
- **逻辑说明书**（`skills/argument-layer.md`）：每次交付附最弱一环、反证动作、换假设测试
- **文件化记忆**（`memory/`）：客户档案、经验沉淀、风格档案跨会话持久
- **案例库与创意骨架**（`skills/case-library.md`）：SK1-SK21，创意从骨架长出来，案例标注骨架组合

## 快速开始

### 在 ChatGPT / Codex 桌面版安装

1. 在本目录运行 `.\install-codex.ps1`（把技能安装到 `~\.codex\skills\marsala\`——Codex 专属技能目录，本机所有 Codex 项目生效）
2. 新建任意 Codex 会话，说「启动 Marsala」，或直接提出营销策略需求（如「帮我的品牌做一次竞品分析」）

> 作用域：Codex 全局，但不是跨工具共用——`~\.codex\skills\` 只有 Codex 读取，不会污染其他 Agent 平台。

### 在其他平台

Marsala 与 Runtime 解耦：任何能读取 Markdown 文件的 Agent 平台都可以加载本仓库内容，但平台迁移不是简单复制——入口、记忆、工具映射需要按平台适配。历史版本（reasonix / claude-code）已停用，仅存于本地存档。

## 能力边界

**能做的：** 品牌策略与营销战役的完整判断链——商业诊断、市场研究、消费者洞察、品牌定位、创意方向、媒介策略，以及每个判断的验证与纠错路径。

**不能做的：** 不写文案、不管投放、不发邮件；不编造数据、不预测精确 ROI、不假装拿到平台内部数据。数据来自外部输入，Marsala 只负责解读与判断。

**可追溯：** 每条判断都能往回追——证据从哪来、推理怎么走、结论站第几层。追不到源头的，Marsala 说不出来。
