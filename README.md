# Marsala

一套应用于品牌咨询和营销策划领域的可执行知识（Executable Knowledge）——以 Markdown 文件承载判断逻辑、工作流程与质量标准的策略系统，与 Agent Runtime 解耦，可在不同平台加载运行。

Marsala 不做执行，只做判断：面对一个商业问题，给出明确的方向、讲清背后的理由，并说明如何验证这个方向对不对。

**Beta 3.6.0 · 本仓库为唯一权威版本（`main` 分支）**

---

## 快速开始

### 在 ChatGPT / Codex 桌面版安装

1. 在本目录运行 `.\install-codex.ps1`——把技能安装到 `~\.codex\skills\marsala\`（Codex 专属技能目录，本机所有 Codex 项目生效；`memory/` 只在首次安装时播种，之后重装不覆盖会话记忆）
2. 新建任意 Codex 会话，说「启动 Marsala」，或直接提出营销策略需求（如「帮我的品牌做一次竞品分析」）

> 作用域：Codex 全局，但不是跨工具共用——`~\.codex\skills\` 只有 Codex 读取，不会污染其他 Agent 平台。若只想让单个项目生效，把技能放进该项目根目录的 `.codex\skills\marsala\`。

### 在其他平台

Marsala 与 Runtime 解耦：任何能读取 Markdown 文件的 Agent 平台都可以加载本仓库内容，但平台迁移不是简单复制——入口、记忆、工具映射需要按平台适配，记录见 [PORTING-NOTES.md](PORTING-NOTES.md)。

内容开发在本地 reasonix 工作区进行（`Desktop\Advertising Strategy Agent\.reasonix\`），本仓库是唯一发布版本；旧的 reasonix / claude-code 远端仓库已停用，只保留本地存档。

## 架构：一中枢六模块

- 🧠 **中枢（客户总监）**：拆解 Brief、调度协作、整合交付、管线熔断
- 🧩 **六个模块**：商业战略（`hand-1`）/ 市场研究（`hand-2`）/ 消费者研究（`hand-3`）/ 品牌策划（`hand-4`）/ 创意总监（`hand-5`）/ 媒介策划（`hand-6`）
- **双模式**：品牌咨询（模块一~四）与营销策划（模块五~六）——一个入口，按问题信号分流；完整项目走「品牌咨询 → 营销策划承接」全管线
- **四层审查**：证据治理 / P&L 经营 / 组织政治 / 危机应对

## 理论结构：双通道各有一套三问三层

Marsala 的研究对象分两条支线，各自有顶层理论：

| 支线 | 理论文件 | 回答的问题 | 三层结构 |
|------|---------|-----------|---------|
| 品牌咨询 | `skills/brand-theory.md` | 品牌如何建立？如何讲述自己？如何长期经营？ | 立身 / 表达 / 存续 |
| 营销策划 | `skills/campaign-theory.md` | 这一波为什么现在打？打给谁、抢哪个时刻？怎么算赢？ | 时机 / 触达 / 沉淀 |

**campaign 是品牌表达的时间切片。** 品牌理论回答品牌应该是什么，战役理论回答这一波怎么把品牌表达出去并算清账。全管线先读品牌理论，再承接战役理论。

## 判断体系：真实 → 正确 → 优秀

三级递进——不真实的不可能正确，不正确的不可能优秀：

| 层级 | 回答的问题 | 判断标准 |
|------|-----------|---------|
| **真实** | 结论站得住吗？ | 每个结论都能追到来源与时点；证据弱就降级，不硬撑 |
| **正确** | 方向能赢吗？ | 不是选出来的，是淘汰出来的——留下的必须能回答「为什么不是它」和「什么能证明它错」 |
| **优秀** | 表达能长出来吗？ | 创意从被验证过的机制里长出来，不靠临时发明；风格靠一次次实践沉淀 |

三级各自落在哪一环，见下节；定义与判断准则见 `skills/core-contract.md`（核心契约）。

## 关键机制

按「质量在哪一环被决定」排列——每一环换掉，交付质量会明显掉：

1. **诊断：把 brief 变成问题**（`skills/account-director.md`）：漏斗式提问（每轮 ≤3 问）、四大默认不信任项（人群定义 / 预算数字 / 渠道选择 / 品牌定位）、假设带概率。这一步决定你是不是在解真问题
2. **证据：加权与熔断**（`skills/evidence-governance.md`）：来源等级（E1-E6）× 时效档位（T1-T3），弱证据降级；只有全部依赖弱证据且无反证路径时才熔断
3. **定位：淘汰而非挑选**（`skills/hand-4-brand-strategy.md`）：九道闸门逐层杀候选，留下的必须回答「为什么不是另一个」和「什么能证明它错」；0 个活时按四类归因决定补数据 / 回退上游 / 承认这单不需要定位
4. **创意：从机制库生成，用三关选择**（`skills/creative-layer.md` + `skills/case-library.md`）：机制扫描（M01–M21）→ 品类适配 → 品牌事实注入；再过三关——去 Logo（去掉品牌名还认得出）、竞争复制（竞品照搬会变成「学你的那个」）、品牌归属（消费者不会误认为别的牌子）
5. **验收：反事实与分离**（`skills/hand-6-media-planning.md`）：不做会怎样（反事实基线）；品类增量 ≠ 品牌增量
6. **交付与沉淀：可拍板、可追溯**（`skills/delivery-rules.md` + `skills/argument-layer.md` + `memory/`）：必备模块 + 三级来源纪律（品牌方输入 / 可查证基准 / 明确占位）+ 逻辑说明书（最弱一环、反证动作、换假设）；复盘回流到风格档案与机制库

## 你会拿到什么

**品牌咨询（模块一~四）：** Executive Summary（一页四块）+ 重构 Brief（问题定义 + 成功标准）+ 定位命题（经九道闸门，附输出声明）+ 落地路径与时间轴 + 量化目标层（含反事实归因）+ 逻辑说明书。

**营销策划（模块五~六）：** Executive Summary + 战役方案（三层目标 → 策略 → 创意方向 → 媒介/内容 → 投资概览 → 三阶段节奏）+ 验收与归因 + 复盘清单 + 逻辑说明书。

两者都带：结论先行、证据等级与数据时点、最弱一环与反证动作、需要你确认的事项；另有「提案蓝图」作为可选附件，供视觉化接手——删掉它不影响交付完整性。拿不到的数据标「占位」，不编造。

## 能力边界

**能做的：** 品牌策略与营销战役的完整判断链——商业诊断、市场研究、消费者研究、品牌策划、创意方向、媒介策略，以及每个判断的验证与纠错路径。

**不能做的：** 不写文案、不管投放、不发邮件；不编造数据、不预测精确 ROI、不假装拿到平台内部数据。数据来自外部输入，Marsala 只负责解读与判断。

**可追溯：** 每条判断都能往回追——证据从哪来、推理怎么走、结论站第几层。追不到源头的，Marsala 说不出来。
