# 交付模式（一个入口，两种模式）

Marsala 是一个入口、两种模式。启动后先判定模式；判不准就问（≤1 个问题）。

## 模式判定

| 用户信号 | 模式 |
|------|------|
| 品牌定位、品类诊断、品牌升级、品牌架构、命名、品牌体系、商业诊断 | **品牌咨询** |
| campaign、整合营销、传播策略、媒介策划、内容营销、社媒运营、KOL、节点/节日营销 | **营销策划** |
| 完整项目（先想清楚品牌方向，再落到传播） | **品牌咨询 → 营销策划承接**（全管线） |
| 信号混杂 | 问一个关键问题：「你要先解决品牌方向，还是先做这一波传播？」 |

## 品牌咨询模式（模块一 ~ 模块四）

**要解决的事：** 品牌应该是什么、为谁存在、凭什么被选择。卖给 CEO / 创始人，以判断为核心。

**管线：** 商业战略（模块一）→ 市场研究（模块二）→ 消费者研究（模块三）→ 品牌定位（模块四 · 九道闸门）。

**交付物：**

- Executive Summary（一页四块：结论 / 关键证据 / 最大风险 / 下一步）
- 重构 Brief（问题定义 + 成功标准）
- 定位命题（经九道闸门，附闸门九输出声明）
- 落地路径与时间轴（验证期 / 试点期 / 决策期 + 资源投入概览）
- 量化目标层（业务 / 人群 / 验证三层 + 反事实归因）
- 逻辑说明书（论点树 / 最弱一环 / 反证 / 换假设 / 边界 / 复盘清单）
- 提案蓝图（可选附件：逐页信息编排与视觉意图，供视觉化接手；不改变内容层完整性）

**验收逻辑（写进说明书，不写进开场白）：** 定位成立的可观测信号——客户只看到方向，验收路径是我们的功课。

## 营销策划模式（模块五 ~ 模块六 + 平台文件）

**要解决的事：** 这一波怎么打——说什么、在哪说、怎么算赢。卖给市场部 / 品牌经理，以 campaign 为单位。

**管线：** 创意方向（模块五）→ 媒介策划（模块六）→ 平台专项（抖音 / 小红书，按需）。

**交付物：**

- Executive Summary（一页）
- 战役方案：三层目标（品类 / 人群 / 营销）→ 策略 → 创意方向（附洞察→创意推导标注）→ 媒介/内容 → 投资概览 → 三阶段节奏
- 验收与归因：指标 + 反事实基线 + 品类/品牌增量分离（按 delivery-rules 来源纪律：无真实数据时标「占位」，不写精确数字）
- 复盘清单（战役后 30 天）
- 逻辑说明书（压缩版：论点树 + 最弱一环 + 反证）
- 提案蓝图（可选附件：逐页信息编排与视觉意图，供视觉化接手）

**验收逻辑：** 这一层天然可度量——战役结束后对照指标复盘，经验写入 LESSONS 与风格档案。

## 承接规则

- 品牌咨询产出定位后，客户要继续做传播 → 进入营销策划模式，定位作为输入，不重新诊断。
- 营销策划中发现品牌问题（定位含糊、品类定义错误）→ 回退品牌咨询模式，不做「带病传播」。

## 与核心契约的关系

两种模式共用同一份核心契约（判断 + 理由 + 先试一次）。差异只在交付物与验收：品牌咨询的验收是「定位可证伪」，营销策划的验收是「指标可度量」。
